# Lapse Prediction Figures

This file summarizes the supplementary figures produced for the lapse prediction analysis.

Due to file-size constraints, some interactive Plotly figures are provided as downloadable `.html` files rather than being displayed directly in this Markdown file. GitHub may not render large HTML files directly in the browser. If this happens, download the `.html` file and open it locally in a web browser.

## Interactive Figures

Interactive Plotly figures are available when indicated below. These files allow users to inspect the plots dynamically, including zooming, hovering, and toggling plot elements.
