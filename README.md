# MFW-rep
Repository containing code and supplementary material for the analysis of insurance policy behavior, focusing on lapse prediction and mid-term modifications. Includes model implementations, hyperparameter settings, and additional results.



## Repository Structure

- `/code/` — Python implementation of models
- `/results/tables/` — Hyperparameter tables and detailed results
- `/results/figures/` — Interactive and static plots
- `/notebooks/` — Analysis notebooks (optional)

## Interactive Plots

Plotly visualizations are provided as `.html` files in the `results/figures/` folder.

To view them:
1. Download the file
2. Open it in a web browser



## Contents

- `/code/libraries.py` — Python libraries used in the analysis.
- `/code/data_preparation.py` — Anonymized data preparation utilities.
- `/code/metrics.py` — Functions for Brier decomposition, ECE, MCE, and model metrics.
- `/code/evaluation.py` — Functions for model evaluation, calibration curves, threshold analysis, and SHAP plots.
- `/code/hyperparameter_tuning.py` — Optuna tuning procedures.
- `/results/tables/` — Hyperparameter tables and additional results.
- `/results/figures/` — Static and interactive figures.

## Data availability

The original dataset is not publicly available due to confidentiality constraints.  
Dataset-specific variable names, internal identifiers, and proprietary preprocessing steps have been anonymized or omitted.
